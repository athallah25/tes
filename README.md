# War of Dots: Frontline (Android prototype)

A landscape Android real-time strategy game prototype. It includes infantry, tanks, aircraft, HQs, credits, neutral resource nodes, capture points, unit selection and movement orders, production buttons, Smart and Divinely Smart AI, pause, and restart.

## Build the APK
1. Create a GitHub repository and upload the contents of this folder (including `.github/workflows/build.yml`).
2. Open **Actions** and run **Build War of Dots Frontline APK** (or push to `main` / `master`).
3. Download `WarOfDots-Frontline-APK` from the completed workflow's Artifacts section.
4. Extract the ZIP and install `app-debug.apk` on an Android device. You may need to allow installation from that source.

This is an unsigned debug APK, intended for testing, not Play Store release. The APK has not been built or device-tested in this environment.
